# Provenance and execution gate

Before this project can be considered complete, the owner must provide:

1. The authoritative upstream repository and exact commit or release from which every source file originated.
2. A license and notices that permit possession, modification, use, and redistribution.
3. A documented explanation for local changes and a review of credential, telemetry, update, process-control, and filesystem behavior.
4. A clean dependency lockfile, reproducible isolated build, security scan, and representative tests.
5. A product owner, intended user, acceptance criteria, data-handling policy, and support/deployment boundary.

No attempt was made to invent these facts or copy in replacement code. `ACKNOWLEDGE_UNVERIFIED_SOURCE=1` only opens the launcher for an owner-approved isolated audit; it does not establish permission, safety, or completeness.
